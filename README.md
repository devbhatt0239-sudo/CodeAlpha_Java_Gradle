# CodeAlpha Java Gradle Project

## Description
This is a simple Java application developed using Gradle as part of the CodeAlpha Internship Task 3.

## Features
- Java application using Gradle
- Student class implementation
- Object-Oriented Programming concepts
- Easy to build and run

## Technologies Used
- Java
- Gradle

## How to Run

Clone the repository:

```bash
git clone https://github.com/devbhatt0239-sudo/CodeAlpha_Java_Gradle.git
```

Go to the project directory:

```bash
cd CodeAlpha_Java_Gradle
```

Run the application:

```bash
./gradlew run
```

Build the project:

```bash
./gradlew build
```
