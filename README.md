# CodeAlpha Java Gradle Project

A simple Java application built using **Gradle** as part of the **CodeAlpha Internship - Task 3**.

## 📌 Project Overview

This project demonstrates the basics of Java application development using the Gradle build tool. It includes a simple `Student` class and an `App` class to demonstrate Object-Oriented Programming (OOP) concepts.

## 🚀 Features

- Java application built with Gradle
- Object-Oriented Programming (OOP)
- Student class implementation
- Simple and easy-to-understand code
- Build and run using Gradle

## 🛠 Technologies Used

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/devbhatt0239-sudo/CodeAlpha_Java_Gradle.git
```

Run the application:

```bash
./gradlew run
```

On Windows PowerShell:

```powershell
.\gradlew run
```

Build the project:

```bash
./gradlew build
```
